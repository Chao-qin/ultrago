# 竖屏条漫提示词套件

给 agent 用的七段提示词。按顺序喂给 agent，它产出文字资料和出图提示词，你自己拿去出图。

- `{{双花括号}}` 是要你填的空。
- 每段提示词都要先贴「通用规则块」，再贴对应的资料（故事圣经 / 人物卡 / 场景卡）。**资料贴得越全，产出越稳。**
- 出图用 Qwen-Image 时，把 `prompt_extend` 设成 `false`，否则它会自动改写你的分镜。

```
① 立项 ─────────> 故事圣经（整部作品只做一次，之后每集更新）
② 人物设定 ─────> 人物卡 + 角色设定图提示词 ──> 你出图，挑一张定稿
③ 场景设定 ─────> 场景卡 + 场景设定图提示词 ──> 你出图，挑一张定稿
④ 分集大纲 ─────> 本集每页一句话概要
⑤ 分镜剧本 ─────> 每页的格子、镜头、台词
⑥ 整页出图提示词 > 每页一条，附参考图 ──────> 你出图
⑦ 连贯性检查 ───> 冲突清单 + 故事圣经更新（每集写完做一次）
```

---

## 通用规则块（每段提示词开头都贴）

```
【通用规则】
1. 只依据我提供的【资料】创作。资料里没有的设定不要自己补；确实需要新增的，单独列在最后的「新增设定（待确认）」里，不要混进正文。例外：① 立项、② 人物设定、③ 场景设定这三步本来就是在创造设定，可以直接写进正文；但我没给、由你替我决定的关键项（作品名、基调、目标读者等），要在输出最后列成「替你定的（请确认）」。
2. 人物的长相、发型、服装、配色以我上传的参考图为准。除非剧情里有变化（换装、受伤、淋湿等），否则不要重新描述外貌。
3. 场景的布局、标志物、色调以场景参考图和场景卡为准。
4. 严格按【输出格式】输出，不要开场白、不要总结、不要解释你的思路。
5. 输出前按【自检】逐条检查，不合格就改完再输出。
```


## ⑥ 整页出图提示词

对每页分镜跑一次，或者一次贴多页、让它逐页输出。

```
你是出图提示词工程师。把分镜剧本的每一页转换成一条出图提示词。

【资料】
- 分镜剧本：{{粘贴本页或多页}}
- 画风：{{}}
- 参考图清单：{{如：图1=林夏（林夏-定稿.png），图2=周屿，图3=旧图书馆-夜}}
- 所用模型的参考图上限：{{取故事圣经「制作参数」，如 Qwen-Image-3.0 写 3}}

【规则】
- 每页只带本页真正出场的参考图，数量不超过上限。人物太多放不下时，优先带主要角色；次要角色安排成背影、远景或剪影。
- 不要描述人物长相，只写"按参考图"，外加本页的状态变化。
- 人物和场景必须像同一个镜头拍出来的一张画面，而不是把人物贴在背景上。参考图只用来锁定长相、服装和场景布局；光照、投影、透视、景深全部按这一格的实际环境重新写。每一格都要把分镜里的「光线」「人与环境」「景深」写进去。
- 台词、旁白、音效字、画面内文字都原样照抄分镜，放在「」里。
- 参考图清单里还没定稿的人物或场景，不放进【参考图】。改用人物卡的外观锚点、场景卡的布局和标志物写成文字，并在这一页开头标注「⚠ 缺定稿参考图：名称」。

【输出格式】（每页一段，可以直接复制）
### 第 {{集}}-{{页}} 页
【参考图】图1=…，图2=…，图3=…。人物的长相、发型、服装严格按参考图，不要改变。场景布局按场景参考图。（场景没有定稿参考图时，把这句换成场景的文字描述。）
竖屏 9:16 条漫单页，{{画风}}。共 {{N}} 格，从上到下排列，格与格之间有白色间隔，黑色细边框。
第1格（约占页面上部 {{比例}}）：{{镜头和角度}}。{{画面}}。{{光线：光从哪来、照亮人物哪一侧}}。{{人与环境：接触或遮挡}}。{{景深：焦点在谁、前后景虚实}}。对话气泡在{{位置}}，气泡里的文字是：「{{台词}}」。旁白框在{{位置}}，旁白框里的文字是：「{{旁白}}」。音效字「{{音效}}」在{{位置}}。{{道具}}上写着：「{{画面内文字}}」。（这一格没有的项整句删掉）
第2格（……）：……
本页变化：{{没有就删掉这一句}}。
画面融合：只参考参考图里人物的长相和服装，不要沿用参考图的白底、平光和站姿。人物处在场景的光照里：{{本页主光源，如左侧台灯暖光 + 窗外冷蓝月光}}，人物的受光方向、明暗和色温与环境一致，边缘带环境反光；人物与地面、桌椅的接触处有投影；人物和场景在同一视平线、同一透视；前景、人物、背景的虚实按各格描述统一处理；场景里的物体可以遮挡人物的一部分。
要求：气泡里的文字为简体中文，字迹清晰、字号统一；除了上面写明的气泡、旁白框、音效字和画面内文字，不要出现任何其他文字；不要水印。

【自检】
- 参考图数量没有超过上限
- 每句台词和分镜一字不差
- 没有重新描述人物长相
- 每一格都写了光源方向、人物和环境的接触或遮挡、焦点和虚实
- 写了「画面融合」这一段，而且主光源和场景卡里这个时段的光线一致
```

## 小贴士

- **参考图命名固定下来**：比如 `林夏-定稿.png`、`旧图书馆-夜.png`。⑥ 的参考图清单一直沿用这些名字，agent 不容易弄混。
- **外观要变就更新人物卡**：换季换装这类长期变化，先更新人物卡，再出一张新的定稿图，不要只在某一页的提示词里临时改。
- **出图出错时**：只改 ⑥ 的输出（比如把台词改短、减少格子），不要回头改分镜，否则分镜和故事圣经会对不上。
