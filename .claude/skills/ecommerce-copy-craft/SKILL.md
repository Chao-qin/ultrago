# 电商内容创作 · Craft 层

写**能转化**的中文电商内容:小红书种草 / 抖音·直播带货脚本 / 抖店·淘宝 商品标题·卖点·详情 / 落地页。

**两层分工(别混)**:本 skill 只管「**怎么写好**」;它**不**判断某句话真不真、合不合规——那是 `insight-to-copy`(有据 + 广告法 + 效度边界)。**craft 写完必须过 insight-to-copy 才能发。** 一句话:craft 管怎么说,insight-to-copy 管能不能说。

## 何时用 / 不用
用于任何**卖货导向**的内容创作。**不**用于:与销售无关的长文、代码/文档、以及**没有产品/卖点可写**时(先去做分析/拿到产品信息)。

## Craft 循环
1. **定位**:一条不矛盾的角(最好来自已审计的洞察 / `semantic-census-analysis` 报告)。
2. **选框架**(见下,一篇一框架)。
3. **先写 hook**——它决定点击/完播,下游都服从它。
4. **套平台结构**(详见 `references/platform-playbooks.md`;框架/心理触发/headline/去AI味细节见 `references/craft-library.md`)。
5. **去 AI 味**一遍。
6. **交 `insight-to-copy`** 过双证据账本 + 禁语表;过不了的主张 → 占位符 / 删。

## 框架工具箱(公开框架,一篇选一个)
| 框架 | 结构 | 何时用 |
|---|---|---|
| AIDA | 注意 → 兴趣 → 欲望 → 行动 | 详情页 / 落地页 / 长文 |
| PAS | 痛点 → 放大 → 方案 | 种草 / 短文 / 评论区 |
| BAB | 之前 → 之后 → 桥梁 | 效果类 / 对比 |
| FAB | 特性 → 优势 → **利益** | 卖点 bullets(务必落到"对用户的利益",别停在特性) |

**铁律**:benefits > features、具体 > 空泛、一节一个观点、主动语态、别编造。

## Hook craft(钩子决定成败)
可用杠杆:**好奇缺口 / 具体数字 / 痛点反差 / 身份认同 / 场景代入 / 社会证明**。
- ❌ 泛:"好用内衣推荐" → ✅ 具体:"圆盘胸一弯腰就空杯?这件站坐都不空"。
- hook 要能一句话戳中**某个具体人群的某个具体场景**,不要"人人适用"。

## 去 AI 味(stop-slop)
删这些 AI 腔:`赋能 / 打造 / 一站式 / 干货满满 / 众所周知 / 在当今…时代 / 不容错过`;删排比虚词与无实质感叹号;别硬堆 `绝绝子 / yyds / 家人们谁懂`(除非品牌调性真如此)。**用具体细节替代形容词堆叠。**

## 平台结构(速览;完整见 `references/platform-playbooks.md`)
- **小红书**:`钩子 + 内容 + 互动结尾`;标题融热搜词(听劝/显眼包/避雷);变体=对比版 / 清单合集 / 避雷版。
- **抖音带货脚本**:`黄金3秒` → `0-3s 钩子(痛点/反差)` → `3-12s 产品+实测+核心卖点` → `12-15s 优惠+引导点击`。
- **抖店/淘宝**:SEO 标题(≤60 字,关键词前置)+ benefit-first 卖点 bullets + 详情分段结构。

## 输出格式
1. **定位**(一句话)
2. **分渠道文案**(每处套对应平台结构)
3. **2-3 个 hook 备选 + 各自理由**
4. 交 `insight-to-copy` 过账本(标出哪些主张需真实商品参数)

- **`references/platform-playbooks.md`** — 小红书 / 抖音带货 / 抖店·淘宝 各渠道的完整结构、标题公式、笔记变体、脚本模板、详情页结构。

## Handoff [RIGID]
craft 产出**必须**先过 `insight-to-copy`(双证据账本 + 禁语 + 效度边界)才算可发;再交 `douyindian-product-ops`(或对应平台)上架——**不代发**,占位符须用真实商品数据填实。

## Rigid vs Flexible
RIGID:出口必过 `insight-to-copy`;hook 要具体不空泛;去 AI 味。FLEXIBLE:框架、tone、平台结构按品牌与渠道调整。
