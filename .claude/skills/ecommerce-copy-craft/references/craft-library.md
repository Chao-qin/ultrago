# Craft Library —— 文案craft通用干货(蒸馏自公开框架与社区实践,中文电商化)

> 这些是**公开的craft知识**(框架/心理学/定价/headline/反AI味),用自己的话改写并映射到中文电商。用于 SKILL.md「选框架/写hook/去AI味」三步。**所有产出仍须过 `insight-to-copy` 合规兜底。**

## 1. 文案框架(一篇选一个)

| 框架 | 结构 | 何时用 | 电商例 |
|---|---|---|---|
| **AIDA** | 注意→兴趣→欲望→行动 | 详情页/落地页/长笔记 | 标题抓睛→展示痛点→实测效果→限时下单 |
| **PAS** | 痛点→放大→方案 | 种草/短文/评论区 | "弯腰空杯"→"整天走光尴尬"→"这件站坐都不空" |
| **BAB** | 之前→之后→桥梁 | 效果/对比 | "以前钢圈勒到喘不过气"→"现在软支撑一天无感"→"换的是这款" |
| **FAB** | 特性→优势→**利益** | 卖点bullets | "软支撑条(特性)→不硬压(优势)→久穿不勒不累(利益)";**务必落到利益** |
| **PASTOR** | 问题→放大→故事/证据→转变→提议→回应 | 长种草/带货口播 | 适合有真实测评/买家故事时 |
| **4U** | Useful有用·Urgent紧迫·Unique独特·Ultra-specific超具体 | 标题/hook自检 | 四条至少中两条才是好标题 |

## 2. 心理触发器(按用途取用,别堆砌)

**建欲望**:社会证明(销量/买家秀/榜单)、稀缺紧迫(**仅真实**限量/限时)、模仿欲(别人都在买)、即时利益("今天就…"胜过"6个月见效")、蔡格尼克开环("已完成80%…"制造完成冲动)。
**降门槛/促行动**:损失规避(损失感≈2倍收益,"别再将就"胜过"你能获得"——**但注意效度边界,别过度概括**)、默认/预选、选项≤3(选择过载会瘫痪决策)、把第一步做到极易(预填/模板/立得小赢)。
**建信任**:权威(资质/专业背书)、退款保证降后悔、瑕疵效应(承认小缺点反增可信,如"缺点是蕾丝款稍显尖")、峰终定律(把最强卖点放开头和结尾)。
**感知价值**:锚定(先出高价/参照款)、对比效应(有对照才显好)、诱饵(次优第三档衬托主推)、禀赋/宜家效应(让用户参与选码/搭配增值)。

## 3. 定价心理(抖店/直播场景)

- **尾数定价**:¥99 比 ¥100 感觉便宜一档;圆整价(¥100)显高端,尾数价(¥99)显实惠——按品牌调性选。
- **100法则**:<¥100 用百分比("立减20%"),≥¥100 用金额("直降50元")。
- **好-中-好**(三档):中间档为主推,贵档做锚点justify中间,便宜档兜底引流。
- **单位重构**:"每天1块钱"比"一年365"更易接受。

## 4. Headline / Hook 公式(奥格威 + 通用)

**标题原则**:
- **品牌+利益+新闻感**:产品名与利益同现;"许诺一个利益"胜过耍机灵。
- **点名人群**:"圆盘胸/孕晚期姐妹…"直接喊目标群。
- **长度**:记忆向 8–10 字、直效向 6–12 字(中文按字数酌情)。
- **信息>机灵**:平白话把新闻点讲清;**避免否定式标题**(降效)。
- **故事化**:一句具体场景细节胜过一堆形容词(劳斯莱斯"时速60最大噪音来自电子钟")。

**Hook 杠杆(钩子决定点击)**:好奇缺口 / 具体数字 / 痛点反差 / 身份认同 / 场景代入 / 社会证明。
- ❌ 泛:"好用内衣推荐" → ✅ 具体:"圆盘胸弯腰就空杯?这件站坐都不空"。
- 4U 自检:有用+超具体是底线。

## 5. Body copy 规则(奥格威)

- **越多越卖**:有真信息时,50–500 字读者留存稳定——别怕写够,怕写空。
- **具体>形容词**:堆事实,少用"超好/绝了"这类夸词(空)。
- **把读者当聪明人**:给证据,别糊弄。
- **提供帮助**:除了卖,给点选购/搭配/护理建议,参与度显著↑。
- **show don't tell**:用实测/对比/数据证明,别只喊结论。

## 6. 去 AI 味(stop-slop 反模式清单)

**删这些开场/强调套话**:"其实/说白了/值得一提的是/敲黑板/让我们…"、"在当今…时代/归根结底/说到底/众所周知"。
**删副词与虚词**:真的/就是/简直/literally式;能删的"地/得"虚词。
**删结构套路**:"不是X,而是Y"式硬反转;先说"不是什么"再揭晓;短句堆叠制造假高级;"想象一下/你有没有想过"式无效反问;让死物"做动作"(如"品质在诉说")。
**中文 AI 腔额外删**:赋能/打造/一站式/干货满满/闭环/抓手/不容错过;硬堆"绝绝子/yyds/家人们谁懂"(除非品牌真如此)。
**改写规则**:①指明主语(谁在做)②直说(去掉否定绕弯)③主动语态④用具体命名替代空泛断言⑤长短句错落、别老三段排比⑥信任读者、少解释软化⑦形容词能删则删,用细节代替。
