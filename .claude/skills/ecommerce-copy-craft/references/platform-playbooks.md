# 平台 Playbook —— 中文电商各渠道的结构套路(社区通用 skill 没有的部分)

> 每个渠道给:整体结构 + 标题/hook 公式 + 内容套路 + 变体 + tone + 坑。craft 时套对应结构,再回 SKILL.md 走「去AI味 → 过 insight-to-copy」。

---

## 一、小红书(种草笔记)

**整体结构 = 钩子 + 内容 + 互动结尾**(钩子定点击率、内容定完播率、结尾定算法推荐权重)。

**标题公式**(任选组合,7–20 字):
`热搜词 + 人群 + 场景 + 具体结果 + 情绪符号`
- 热搜词/口语钩:听劝 / 显眼包 / 避雷 / 谁懂啊 / 真的会谢 / 本命 / 相见恨晚
- 例:「圆盘胸姐妹听劝!弯腰不空杯的内衣真的存在」「避雷⚠️这3种内衣大胸千万别买」
- 铁律:热搜词要**与产品强关联**,不生硬堆;标题里给**具体结果/冲突**,不泛泛。

**正文套路**:开头 1–2 句复现痛点场景(代入)→ 中段给"我试过/对比/怎么选"的实质内容(可信)→ 结尾抛问题/求同(互动:"你们也这样吗?""求同款尺码的扣1")。

**笔记变体(选一)**:
- **测评版**:多款横评,给结论表(最贴需求)
- **对比版**:"我同时买了 A 和 B"结构展开优劣
- **避雷版**:"这几种别买 + 为什么"(负向钩子,点击高)
- **清单合集**:"XX 场景必备的 5 样",核心结构跨品类复用、只换品名/卖点/人群
- **教程/科普版**:"圆盘胸怎么量码/怎么选杯型"(建信任,软带货)
- **剧情/自述版**:第一人称转折故事(PASTOR 框架)

**tone**:像姐妹分享,不像广告;真实细节 > 完美摆拍;适度 emoji 断句。
**标签**:精准人群+品类+场景标签(#大胸内衣 #圆盘胸 #无钢圈内衣 #内衣分享);**别用"#测评"给自家带货**(误导,换 #分享/#体验)。
**坑**:满屏软广壳词(聚拢/显小/提拉/封神)会被判营销+反感;别过度概括("人人必入")——效度边界由 insight-to-copy 兜。

## 二、抖音 / 直播带货脚本

**黄金3秒 + 15秒结构**:
```
0-3s   钩子:痛点 / 反差 / 悬念(留住人)——"大胸穿衬衫崩扣?看这件"
3-12s  核心:展示产品 + 实测效果 + 核心卖点(2-3个,别贪多)
12-15s 转化:优惠(限时/赠品)+ 明确引导("点下方小黄车/3号链接")
```
**口播要点**:一句一个信息点、短句、有节奏;先给结果再给原因;数字/对比增强可信;每段留"接话"给下一段。
**长脚本**(直播/长视频)用 PASTOR / AIDA 展开;痛点→实测→卖点→价格锚点→催单话术(真实稀缺)。
**坑**:功效/绝对化话术(治疗/最/第一)是平台+广告法红线,由 insight-to-copy 拦;别口播编造销量/资质。

## 三、抖店 / 淘宝(商品页)

**SEO 标题(≤60 字,关键词前置)**:
`人群/品类 + 核心卖点 + 材质/工艺 + 场景`
- 例:`大码大胸内衣女无钢圈软支撑不勒 圆盘胸大杯薄款透气无痕`
- 关键词取自真实搜索词(买家会搜的),前置放高权重词;别堆无关词。

**卖点 bullets(FAB,落到利益)**:每条 = 特性→优势→**对用户的利益**;3–7 条;benefit-first;体感词(不勒/不闷/不空杯)>参数堆砌;`[方括号]`标待实证。

**详情页结构(自上而下)**:
1. 主图/首屏钩子(痛点或人群点名)
2. 痛点场景(代入)→ 3. 解决方案(产品如何解)→ 4. 核心卖点分点(配图/实测)
5. 使用场景/搭配 → 6. 信任(资质/材质/买家反馈)→ 7. 尺码指引(选码表)→ 8. CTA/规格/售后
**主图文案**:一图一卖点,3–6 字短词,别整段。

**坑**:抖店铁律=只用真实商品数据、不编造品牌/资质/销量、标题≤60、发布前回显确认(见 `douyindian-product-ops`);功效/绝对化词由 insight-to-copy 先清。

## 出口(所有渠道通用)
craft 写完 → **去 AI 味** → **过 `insight-to-copy`**(双证据账本:每句 = 报告发现锚点 + 真实商品证据;广告法/软广禁语;效度边界)→ 交 `douyindian-product-ops`(或对应平台)上架,**不代发**,占位符须填真实数据。
