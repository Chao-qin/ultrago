# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's private vulnerability reporting for this repository. Include the affected version or commit, impact, reproduction steps, and any suggested mitigation. Do not attach real credentials, cookies, account exports, or customer data.

## Supported Versions

Security fixes are applied to the latest release and the default branch.

## Secret Handling

Keep `.env`, shop profiles, browser data, session captures, and generated reports local. Revoke exposed credentials immediately; removing a value from a later commit does not invalidate it or erase prior copies.
