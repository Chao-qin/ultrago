安装扩展
  1. 打开 chrome://extensions，开启“开发者模式”。
  2. 点击“加载已解压的扩展程序”，选择扩展目录。
  3. 以后用桌面上的「Chrome（UltraGo）」打开 Chrome：后台任务窗口被其他窗口挡住时仍会继续渲染。先彻底退出 Chrome（Windows：任务栏里不剩 Chrome；macOS：按 ⌘Q 退出），再用它打开。
只连接了一个 Chrome 时会自动确认；所选浏览器离线时不会切换到其他浏览器。

模型用来做什么

  • 验证码提醒：任务被验证码或人机验证挡住时，客户端把页面截图交给本机模型确认，再在工作台「事件通知」里提醒你去处理。截图只交给本机模型，不会发到云端。
  • 模型接口：工作台「LLM 网关」把这里的模型提供给脚本和流程调用，并记录每次调用。

不设置会怎样

  • 任务卡在验证码时不会提醒，需要你自己去任务窗口查看。
  • 需要模型的脚本和流程无法运行。
  • 不受影响：浏览器连接、采集模板，以及 Claude、Cursor 等 AI 助手（它们用自己的模型）。
