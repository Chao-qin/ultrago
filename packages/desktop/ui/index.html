安装扩展
  1. 打开 chrome://extensions，开启“开发者模式”。
  2. 点击“加载已解压的扩展程序”，选择扩展目录。
  3. 以后用桌面上的「Chrome（UltraGo）」打开 Chrome：后台任务窗口被其他窗口挡住时仍会继续渲染。先彻底退出 Chrome（任务栏里不剩 Chrome），再用它打开。
